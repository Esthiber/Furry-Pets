# Furry-Pets

Bienvenido a **Furry-Pets**, una aplicación dedicada a la gestión y adopción de mascotas peludas. Este proyecto está diseñado para ayudar a refugios, rescatistas y amantes de los animales a conectar, gestionar información y promover la adopción responsable.

## Características principales

- Registro y gestión de mascotas disponibles para adopción.
- Perfil detallado de cada mascota (nombre, edad, especie, características, fotos).
- Sistema de búsqueda y filtrado por especie, edad, tamaño, etc.
- Panel para administradores y colaboradores.
- Publicación de historias de adopción y seguimiento de mascotas adoptadas.
- Notificaciones y contacto para interesados en adopciones.
- Interfaz intuitiva y amigable.

## Tecnologías utilizadas

- **Frontend:** Vanilla CSS
- **Backend:** Blazor
- **Base de datos:** SQLServer 2019
- **Otros:** ...

## Instalación

1. Clona el repositorio:
   ```bash
   git clone https://github.com/Esthiber/Furry-Pets.git
   ```
2. Instala las dependencias:
   ```bash
   dotnet 
   ```
3. Ejecuta el proyecto:
   ```bash
   dotnet
   ```
